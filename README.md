# OpenClaw Workspace - ARES

## Primary Storage
**USB:** `/Volumes/QUINN/openclaw_workspace/` (primary)
**Local:** `~/.openclaw/workspace/` (mirror)

## Structure
```
workspace/
├── SOUL.md          # Agent identity
├── USER.md          # User info
├── AGENTS.md        # Operating principles
├── MEMORY.md        # Long-term memory
├── TOOLS.md         # Tool notes
├── HEARTBEAT.md     # Periodic checks
├── handoff.md       # Session handoffs
├── memory/
│   ├── daily/       # Daily logs (YYYY-MM-DD.md)
│   └── archive/     # Old memories
└── skills/          # Custom skills
```

## Sync
USB is primary. Local mirrors automatically.
